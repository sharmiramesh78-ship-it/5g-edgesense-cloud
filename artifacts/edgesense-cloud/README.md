# 5G EdgeSense Cloud

A runnable industrial IoT dashboard demo with a FastAPI backend and a plain
HTML, CSS, and browser JavaScript frontend. It simulates three machines and
generates a new temperature sample for each machine every three seconds.

**All machine readings, connectivity values, and alerts in this app are
simulated. They do not come from real equipment.**

## Run in this workspace

The project uses Python 3.11 or newer. From the workspace root:

```bash
python -m pip install -r artifacts/edgesense-cloud/requirements.txt
python -m uvicorn backend.main:app --app-dir artifacts/edgesense-cloud --host 0.0.0.0 --port 8000 --reload
```

Open `http://localhost:8000`. FastAPI serves both the dashboard and API in this
standalone run. In the Replit preview, the dashboard and FastAPI API run as
separate web and API services. The dashboard refreshes automatically every
three seconds. Pause or resume the live view from the dashboard; readings
continue to be generated by the backend while the browser is paused.

## API

- `GET /api/healthz` — service health
- `GET /api/dashboard` — summary, machines, recent readings, and alerts
- `GET /api/machines` — current machine state and 5G connectivity
- `GET /api/readings?limit=60` — recent readings for each machine
- `GET /api/alerts?limit=20` — recent overheating events

The interactive API documentation is available at `/api/docs`.

## Tests

```bash
python -m unittest discover -s artifacts/edgesense-cloud/tests -v
```

## Project layout

- `backend/main.py` — FastAPI routes and three-second simulator lifecycle
- `backend/simulator.py` — in-memory machine, reading, and alert generation
- `index.html` — dashboard document
- `static/css/dashboard.css` — responsive dashboard styles
- `static/js/dashboard.js` — polling, controls, visualization, and UI updates
- `tests/test_api.py` — basic API behavior tests

Telemetry is intentionally held in memory and resets when the server restarts.
This demo has no real devices, cloud platform, external service, or paid-service
dependency.
